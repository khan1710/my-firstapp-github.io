# Медицинская База — Offline

Оффлайн-справочник: болезни, симптомы, лабораторные нормы,
каталог препаратов и калькулятор ИМТ. Работает без интернета.

## Возможности

- 🔍 Поиск болезней по названию / МКБ / синониму
- 🌡️ Фильтры по сезону и системе органов
- 🩺 Выбор симптомов с подсчётом совпадений
- 🧪 Справочник лабораторных норм (М/Ж/дети)
- 💊 Каталог препаратов (Rx / OTC, поиск, сортировка по цене)
- ⚖️ Калькулятор ИМТ
- 🌓 Тёмная / светлая тема (сохраняется в localStorage)

## Запуск локально

Откройте `index.html` в браузере. Никаких сборок не требуется.
